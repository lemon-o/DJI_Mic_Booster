# USB_Mic_Booster 详细用户使用手册 (User Guide)

欢迎使用 **USB麦克风增益助手 (USB_Mic_Booster)**！本文档将指导您完成驱动安装、设备配置、增益调优以及在各大主流会议与直播软件中的无缝接入。

---

## 1. 为什么需要本软件？

使用各类 USB 麦克风（如 USB 桌面麦克风、DJI Mic / DJI Mic 2 / DJI Mic Mini 等无线领夹麦克风、各类板载/外置声卡麦克风）连接 Windows 电脑时，许多用户会遇到**“声音太小”**或**“别人听不清”**的问题：
- Windows 系统内置的声卡麦克风增益经常被锁定（显示 0 dB 且无法提升）；
- 硬件设备自带的增益调节档位有限；
- 如果直接通过其他大型调音软件放大，往往操作繁琐、经常爆音破音，而且软件常驻后台占用大量 CPU 和几百兆内存。

**USB_Mic_Booster (USB麦克风增益助手)** 通过底层的 Windows 原生音频流引擎，实时为麦克风提供干净的数字增益与智能防爆音限幅，体积仅约 360 KB，内存仅占用约 5 MB，开机即可在后台静默运行。

---

## 2. 准备工作：安装虚拟音频线 (VB-CABLE)

要让会议或游戏软件听到经过放大的声音，需要使用一条“虚拟音频线”将放大后的声音传输过去。

1. 进入本项目根目录下的 `VBCABLE_Driver` 文件夹；
2. 找到 `VBCABLE_Setup_x64.exe`，**右键单击并选择“以管理员身份运行”**；
3. 点击弹出窗口中的 **Install Driver** 按钮；
4. 驱动安装完成后，建议重启一次电脑（或重新插拔耳机）以确保系统音频服务刷新。

> 💡 **原理提示**：
> 安装驱动后，系统会新增两个设备：
> - **`CABLE Input (VB-Audio Virtual Cable)`**：本软件将声音送入的虚拟输入端口。
> - **`CABLE Output (VB-Audio Virtual Cable)`**：供其他第三方软件选用的虚拟麦克风端口。

启动 `USB_Mic_Booster.exe` 后，您将看到极简现代扁平化主控制面板：

### 3.1 麦克风输入选择
- **下拉菜单**：点击下拉菜单，选择您的实际硬件麦克风（如含有 `USB`、`DJI`、`Wireless Mic` 或您的声卡麦克风名称）。
- **刷新按钮**：如果您在启动软件后才插入或连接麦克风，点击右侧的 **[刷新]** 按钮即可重新枚举最新设备列表。
- **自动绑定**：软件会在后台全自动静默寻找并绑定 `CABLE Input` 虚拟声卡作为放大后输出，无需手动设置复杂的输出线路。

### 3.2 增益调节与常用预设
- **无级滑动条**：支持在 `0.0 dB`（原声直通）到 `+30.0 dB`（约 31.6 倍信号放大）之间微调，步进精度为 0.1 dB。
- **快捷预设按钮**：
  - `+6dB`（约 2.0 倍放大）：轻度提升，适用于距离麦克风非常近的场景；
  - `+12dB`（约 4.0 倍放大）：标准提升，适合常规桌面或领夹拾音；
  - `+14dB`（约 5.0 倍放大，**推荐默认档**）：声音饱满清晰，适合大多数日常语音、会议交流；
  - `+18dB`（约 7.9 倍放大）：适合大空间远距离收音、轻声细语交流；
  - `+22dB`（约 12.6 倍放大）：超大增益，适合极弱信号或远距离环境拾音。

### 3.3 实时输出电平表 (VU Meter)
- 说话时电平柱会实时跳动：
  - **绿色区域 (0% ~ 70%)**：安全健康的人声电平；
  - **黄色区域 (70% ~ 90%)**：充沛饱满的动态区间；
  - **红色区域 (90% ~ 100%)**：极高电平区间。内置的**软限幅器 (Soft Limiter)** 会自动启动平滑压制，防止出现刺耳爆破破音。

### 3.4 选项设置
- **[ ] 开机自启动**：勾选后，开机自动随 Windows 启动。
- **[ ] 静默启动 (仅驻留系统托盘)**：配合开机自启动使用。开机时直接后台驻留托盘，不弹出窗口打扰日常使用。当您日常在桌面主动双击程序时，依然会正常弹出主界面。

## 4. 系统托盘与后台常驻操作

点击窗口右上角的关闭按钮 `×` 或最小化按钮 `—`，软件会自动隐藏并常驻在 Windows 任务栏右下角的系统托盘中：

- **左键单击 / 双击托盘图标**：快速呼出 / 还原主界面。
- **右键单击托盘图标**：弹出快捷菜单：
  - **打开主界面**：置顶还原控制面板；
  - **静音麦克风**：一键切换全局静音（麦克风静音后，电平归零，第三方软件接收静音）；
  - **开机自启**：快捷勾选/取消开机自启；
  - **静默启动**：快捷勾选/取消静默启动；
  - **退出程序**：彻底退出软件并释放所有音频通道。

## 5. 主流通讯与录音软件接入实操

完成以上配置后，将您使用的第三方软件的音频输入改为 **虚拟音频输出** 即可：

### 5.1 腾讯会议 (Tencent Meeting)
1. 打开腾讯会议，进入【设置】 -> 【音频】；
2. 在 **麦克风** 选项中，下拉选择：
   👉 `CABLE Output (VB-Audio Virtual Cable)`；
3. 对着麦克风讲话，观察腾讯会议中的麦克风音量跳动条，确认收音饱满清晰。

### 5.2 OBS Studio 直播与录制
1. 打开 OBS Studio，进入【设置】 -> 【音频】；
2. 在【全局音频设备】的 **麦克风/辅助音频** 中，选择：
   👉 `CABLE Output (VB-Audio Virtual Cable)`；
3. 在主混音器面板中即可看到麦克风电平处于健康绿/黄色区间。

### 5.3 Discord 开黑连麦
1. 打开 Discord，点击左下角【用户设置】（齿轮图标） -> 【语音与视频】；
2. 在【输入设备】中，选择：
   👉 `CABLE Output (VB-Audio Virtual Cable)`；
3. 将输入音量滑块拉至 100%，输入模式建议设为“按键说话”或调整“输入灵敏度”。

### 5.4 微信 Windows 电脑版
1. 打开微信，点击左下角菜单 -> 【设置】 -> 【音视频通话】；
2. 在【麦克风】下拉列表中选择：
   👉 `CABLE Output (VB-Audio Virtual Cable)`。

## 6. 常见问题排查 (FAQ)

### Q1: 在其他软件里找不到 `CABLE Output`？
**解答**：说明虚拟声卡驱动未安装或未生效。请打开本目录下的 `VBCABLE_Driver` 文件夹，右键管理员运行 `VBCABLE_Setup_x64.exe` 完成安装并**重启电脑**。

### Q2: 软件说话时听不到声音，电平表也不动？
**解答**：
1. 检查麦克风硬件连接是否正常、是否已开机或通电；若是无线麦克风，检查接收器与发射机是否已配对；
2. 检查主界面顶部的麦克风下拉菜单是否正确选择了您的麦克风，若刚插上可点击【刷新】；
3. 检查是否开启了【静音麦克风】。

### Q3: 声音放大后有轻微背景底噪？
**解答**：
任何麦克风在做前级数字高增益放大时，物理环境中的细微底噪（如电脑风扇声、空调风声）都会被等比例放大：
1. 若麦克风自带硬件降噪功能，可开启降噪；
2. 适当降低增益档位（推荐从 `+12dB` 或 `+14dB` 开始调节）；
3. 开启腾讯会议 / Discord / OBS 内置的“AI降噪”或“噪声抑制 (RNNoise)”功能，配合使用效果极佳。

### Q4: 再次双击打开程序为什么没有任何新窗口？
**解答**：本程序内置了**防多开机制**。当程序已经在托盘或后台运行时，再次双击 `USB_Mic_Booster.exe` 会自动唤醒并置顶已经存在的窗口，不会重复创建多个进程抢占声卡。
